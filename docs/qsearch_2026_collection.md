# QSearch：2026 大稻埕煙火查詢與匯出

狀態：已查閱官方操作文件並從本機 MySQL 讀取 2026 活動日期；尚未登入 QSearch、未下載貼文，也未產生實際文字雲。

## 1. 這個工具能提供什麼

QSearch Trend+ 搜尋其收錄的社群、新聞與論壇內容，提供貼文數、留言、分享及文字雲。不同渠道的指標不同；Facebook 的「聲量」是貼文數、留言數與提及留言數的組合，「影響力分數」則是加權值。先取分開的原始指標，避免把加權分數、文章篇數或搜尋人數混用。

目前建議先用學校授權或申請試用，確認帳號能查 2026 年 7–8 月，並可匯出文章 Excel。官網公開方案的資料期間與渠道依方案而定；尚未確認試用帳號的實際匯出權限，不直接購買或註冊付費方案。

## 2. 查詢設定

主題名稱：`2026 大稻埕煙火｜活動前七天`

將下列搜尋式貼進關鍵字搜尋欄；AND／OR 使用大寫，兩旁保留空格：

```text
大稻埕 AND (煙火 OR 花火 OR 夏日節)
```

這是待抽樣確認的初始搜尋式，並非已驗證完整召回率。先閱讀約 20 篇結果，確認是否混入舊年份回顧、無關旅遊或其他煙火活動，再記錄任何查詢修改。不要先加入「下雨」「捷運」「無人機」作必要條件，否則會預先偏向我們想找的主題。

先做第一場，確認結果及匯出內容再做另外兩場。渠道先選帳號有授權的 Facebook、論壇與媒體；IG、Threads 可另做補充，三場應保持相同來源設定。沒有權限或沒有收錄不等於 0 篇。

## 3. 看文字雲

1. 完成關鍵字、時間及渠道設定後，開啟「文字雲 Word Cloud」模組。
2. 點選字詞可查看包含該詞的文章，核對它代表的實際語意。
3. 模組右上角匯出 PNG 供簡報使用，另匯出 Excel 保留字詞資料。
4. 三場各留一張，先比較主題；不要把同名詞在不同圖中的字體大小直接當成跨圖可比的數量。

**內建文字雲不是所有符合條件文章的單純詞頻。** 官方說明指出，它從互動／影響力較高的文本取詞，並用反向詞頻及排除字過濾。因此適合作為探索性摘要；若要據此建立回歸特徵，需另保留文章資料，清楚記錄抽樣／排序方式。

## 4. 下載文章

1. 開啟「熱門文章 Hot Posts」。
2. 點右上角選單，選擇匯出 Excel（需要文章資料，不是只下載 PNG）。
3. 匯出完成後，從「匯出資料列表」下載；依介面提供的欄位選擇完整文章資料。
4. 官網目前記載跨渠道單次最多匯出 10,000 篇。記下符合條件的總筆數與實際匯出筆數；超過上限時先詢問如何取得完整資料，或按日、按渠道拆分查詢後去重。**未確認匯出完整前，不將熱門文章清單當作全量資料。**
5. 原始 Excel 放入：

```text
C:\Users\User.DESKTOP-4RV84M1\Desktop\統計\碩二上\統計實務\data\original_data\qsearch\2026
```

建議第一份命名為 `qsearch_20260725_pre7_posts.xlsx`；字詞表命名 `qsearch_20260725_pre7_words.xlsx`，圖片命名 `qsearch_20260725_pre7_wordcloud.png`。若分渠道，再加 `_facebook`、`_forum`、`_news` 後綴。

下載後檢查實際欄位，優先保留：原文 ID／URL、發表日期時間、渠道、標題、內文、留言／分享／心情數，以及匯出時間。內文是否完整、是否只有摘要，要以實際匯出檔確認。不要把貼文文字、留言文字、YouTube 標籤不加區分地混在一起。

每次匯出另記錄搜尋式、日期、時區、渠道、排序、篩選、符合總筆數、實際筆數與是否達到上限；避免下一次查詢時無法重現。

## 5. 取得檔案後的分析方式

先按原文 ID／URL 去重，標記相同文案的轉載；保留原文另做清理副本。繁體中文斷詞時將「大稻埕」「無人機」「交通管制」等詞完整保留。常見虛詞、網址及主題必然包含的「大稻埕」「煙火」可列為文字雲的顯示排除詞，但不要從原文或主題分類資料刪除。

第一版以「包含該詞的文章篇數」作字體大小，同一篇重複提到同一詞只計一次；新聞／官方宣傳與一般社群分開觀察。這是我們預定的可重現圖表規則，與 QSearch 原生文字雲演算法不同。

後續用每日主題篇數計算活動前 1／3／7 天平均；先把文字雲當成候選主題線索，人工檢查語境與否定用語後再定義分類規則。若用 2026 年資料挑詞，2026 年就不是完全未看過的測試資料。

做事前預測時，不使用當日／事後文章。今天匯出的互動數、熱門排序和修改後內文未必反映活動前當時的狀態；若沒有歷史快照，需標示限制。第一版優先使用依發表時間篩選的文章文字與篇數，互動數只做探索性描述。

QSearch 有官方 API 服務，但需確認授權、文件及可用期間。未取得文件前不猜端點，也不要求使用者把密碼或 token 貼在聊天中。這次先使用官方介面的查詢及匯出流程。
