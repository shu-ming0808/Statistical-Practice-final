## Lasso 那頁可以直接這樣講

> 我們有做 Lasso，想檢查刪減變數能不能改善預測。隊友另外比較了兩種縮放方式及懲罰強度。原縮放下，Lasso 的 MAE 是 848.52，相對同程序重新調參的 Ridge 851.20 只改善 2.68；全欄標準化後，Lasso 幾乎跟 OLS 一樣，36 個編碼欄也全部保留。所以目前沒有得到明顯的預測或稀疏優勢。它保留作對照，主要預測仍使用這九場表現較好的 XGBoost。

注意：

- 不能說「Lasso 一定比較差」；本案原縮放下確實略優於重新調參 Ridge。
- 全欄標準化 Lasso 為 846.37、OLS 為 846.33；保留 36/36 是編碼欄，不是原始變數數量。
- 848.52 是逐年用過去資料選參後的合併結果；圖上 824.55 是事後看九場路徑的最低點，未採用。
- 凍結 Ridge 為 845.44；隊友重新調參 Ridge 為 851.20，不能在表中互換。
- 隊友的訓練程式不齊；目前是輸出與表格核對，未完成端到端重現。

Lasso 的 L1 約束可產生零係數，是方法本身的性質；是否在這份資料得到更好預測，仍要看實證。[Tibshirani（1996）](https://doi.org/10.1111/j.2517-6161.1996.tb02080.x)

## 老師可能追問

**為什麼不改用 Lasso？** 有比較；本案缺乏足夠的預測與稀疏優勢。這是資料結果，不是對方法優劣的普遍結論。

**既然融合沒有更好，為什麼做過？** 融合是待驗證假設；比較後不採用，也是有用的模型選擇結果。不能為了保留方法而強行使用。

**調參是不是偷看答案？** 程式按過去年份切分，但研究過程已反覆看九場結果；因此明確定位探索性回顧比較，不能宣稱完全未見資料表現。

**已經降本增效了嗎？** 還不能這樣說。目前主方案是增加支出換較短等待；減班能省錢但增加等待，需先確定服務偏好與成本口徑。

**為什麼不是 M/M/c？** 列車依班表批次服務、容量有限且散場需求非定常，本案以分鐘隊伍與列車事件模擬；沒有宣稱現有小時資料已證明 Poisson 或指數服務假設。
