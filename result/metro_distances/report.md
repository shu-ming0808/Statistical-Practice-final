# 官方距離資料與增班里程

2026-10-26 已匯入 MySQL `taipei_metro_analysis`。來源：[臺北捷運系統票價與最短距離](https://data.taipei/dataset/detail?id=4acb4911-0360-4063-808d-fcee629508b3)，版本 1150929（2026-09-29），單位公里。

## 查到的距離

| 路段 | 沿松山新店線距離近似（公里） | 用途 |
|---|---:|---|
| 松山—新店 | 18.77 | 全程單向服務成本參考 |
| 松山—台電大樓 | 11.24 | 短程區間參考，未作本次成本方案 |
| 松山—北門 | 7.04 | 松山到北門行車路段 |
| 新店—北門 | 11.73 | 新店到北門行車路段 |
| 台電大樓—北門 | 4.20 | 台電大樓到北門行車路段 |

這些是自行加總的沿線近似里程，不是官方公布的單班完整新增里程。依[官方相鄰站時間資料](https://data.taipei/dataset/detail?id=513e97fe-6a98-4a0d-b7dc-11122c8638d4)的站序，逐段取相鄰站最短距離再相加；原距離已取位至 0.01 公里，仍有取位誤差。

松山—新店的官方端點最短距離為 16.81 公里，沿綠線加總則為 18.77 公里。端點最短路徑可能跨線，不能代替列車實際行駛路線。起站—北門也只是整趟的一部分，不能代替整班成本。

## 尚未取得的資料

- 每場實際派車位置、出入庫路徑及其里程。
- 加班車是否接續其他營運、空車回送或轉作另一班。
- 折返及股道移動等站間距離以外的里程。

[官方工程說明](https://www.dorts.gov.taipei/cp.aspx?n=71ACC5B0CDFFC313&s=CBD13A8895C4EF94)有新店機廠及小碧潭支線的背景，但工程長度不能直接當成每次加班車的出入庫里程。本次未找到可核實活動逐班完整調度／回送里程的公開紀錄。

## 成本情境

暫沿用使用者提供的 128.05 元／列車公里：

| 情境 | 每個新增服務班次的計價里程 | 試算費用（元） |
|---|---:|---:|
| 僅計單程服務 | 18.77 km | 2,403.50 |
| 單程服務＋假設一次全程空車回送 | 37.54 km | 4,807.00 |

計算保留未取位值。第一種只計服務部分，不代表完整邊際成本；第二種的回送是假設，也不是完整成本上界。回送不計成可供北門乘客上車的服務班次，未模擬其效益或路線衝突。128.05 的列車公里／車廂公里口徑及幣值基年仍待核對。

## 資料庫

| 資料表／檢視表 | 筆數 | 內容與關聯 |
|---|---:|---|
| `metro_source_snapshot` | 新增 1 | 官方網址、版本、下載時間、SHA-256 |
| `metro_od_distance` | 14,161 | 119 個站名距離矩陣及票價；PK＝來源＋起站＋訖站，FK 連來源表 |
| `metro_route_distance_segment` | 29 | 綠線兩區間路段；FK 連官方站間時間及 OD 距離 |
| `v_metro_route_distance` | 2 | 由相鄰路段與距離 JOIN 後 SUM 的沿線總距離 |

原檔 17,424 列，轉乘站重複列造成 3,263 筆完全相同的起訖資料，確認值一致才合併；同一鍵不同值會拒絕匯入。「新埔↔新埔民生」原距離為零，原樣保留，但不能當作零長鐵軌路段，綠線加總未使用這組資料。

採交易、既有值衝突檢查與逐值讀回比對。第二次匯入新增零筆；既有 `analysis_event_station_hourly` 維持 74,880 筆。未知回送里程未存成實測零，路徑 CSV 未知欄位留空。成本假設存設定檔，與官方距離分開。

```sql
SELECT route_name, service_km
FROM taipei_metro_analysis.v_metro_route_distance;
```
