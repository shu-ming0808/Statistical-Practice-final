# 分鐘權重倍率整合報告

本目錄是報告的單一來源。閱讀請從 [integrated_report.md](integrated_report.md) 開始。

九場、54 小時的資料內小時 MAE 在 `k=1.05` 最低，為 **437.14** 人次／小時（原設定 `k=1.00` 為 440.28）；若只看九場各自的實際尖峰小時，雙向 MAE 在 `k=1.06` 最低，為 **665.92** 人次／場（原設定為 747.14）。倍率繼續增加雖會減少低估，也會增加高估，不能單看低估選擇 `k`。

| --- | --- |

分析程式使用的九場逐時封存預測 CSV 未收錄在本目錄；重算實驗需提供與報告記載的 SHA-256 相符的檔案。已產生的數值、圖表和表格則可直接閱讀與核對。
